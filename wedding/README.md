# Wedding Invitation 💍

A **separate, self-contained** invitation, independent of the Katb Ketab
invitation at the repository root. Editing anything here does **not** affect
the root invitation, and vice-versa.

- Live path (once Pages is enabled): **https://theaviator4.github.io/OR/wedding/**
- English: `index.html`  ·  العربية: `ar.html`

## Editing

Open **`config.js`** in this folder and change the values in quotes — names,
date, venue, map link, dress code, palette, photos and music. It uses its own
copy of `v2.css`, `v2.js` and `assets/`, so nothing is shared with the root.

## Preview locally

```bash
python3 -m http.server 8000   # then visit http://localhost:8000/wedding/
```
